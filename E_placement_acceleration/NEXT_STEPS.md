# 方案 E 继续研究入口

当前已具备目录、配置、实验计划和可运行合成参考。建议下一次会话先运行 `python3 scripts/run.py check` 与 `python3 scripts/run.py smoke`，再开展下面的第一项实质工作。

1. 选择 VPR 或匹配目标器件的开源布局器，导出候选评估输入和可重复的 CPU 基线。
2. 先选择一个现有布局器及数据适配器，定位候选评估热点；不要直接从零实现完整布局器。
3. 把真实数据接入 `adapters/`，记录版本、字段映射、哈希与必要的语义检查。
4. 复现 [EXPERIMENTS.md](EXPERIMENTS.md) 中最接近的基线，然后选择一个具体迁移机制。
5. CPU 保留接受决策/复杂合法化；FPGA 先加速一个连续批量计算阶段。
6. 根据实测热点决定硬件范围：pin/net 聚合、候选代价归约、资源约束检查与位置快照读取；解析内核另建实验组。

可以直接给下一次助手的任务描述：

> 在方案 E 目录继续研究“异构约束布局加速”。先阅读 AGENTS.md、README.md、EXPERIMENTS.md 和 NEXT_STEPS.md，保留其他方案目录及原始参考代码。当前只有 CPU 合成样例，不要把它当作真实基准。优先完成：选择 VPR 或匹配目标器件的开源布局器，导出候选评估输入和可重复的 CPU 基线。 对方法迁移保持开放，依据具体机制与实验判断贡献。
