# 方案 D 继续研究入口

当前已具备目录、配置、实验计划和可运行合成参考。建议下一次会话先运行 `python3 scripts/run.py check` 与 `python3 scripts/run.py smoke`，再开展下面的第一项实质工作。

1. 导出真实图查询，建立路径回溯、代价和合法性参考；区分一般 Dijkstra 与现有启发式搜索语义。
2. 优先阅读 f_min_search.v、cen_node_ctrl.v、cost_ctrl.v，并对照 main.cpp 的优先队列和 gpu_route.cu 搜索。
3. 把真实数据接入 `adapters/`，记录版本、字段映射、哈希与必要的语义检查。
4. 复现 [EXPERIMENTS.md](EXPERIMENTS.md) 中最接近的基线，然后选择一个具体迁移机制。
5. 沿用 gpuFloodConnection 层次卸载完整连接；先返回完整路径，由 CPU 提交。
6. 根据实测热点决定硬件范围：候选选择 → 邻接流 → 代价计算 → 松弛/依赖处理 → 再入队；回溯单独输出。
