# Bounded per-net canonical-node retention

`search_retained_nodes_top` retains each net's last canonical node set, enabling
old occupancy release without reading the host's retained route result map.
It stores sorted `(net<<32)|node` pairs in two external banks. Net IDs include
zero and UINT32_MAX; no special IDs act as sentinels. Canonical node identity is
supplied by the existing graph adapter and is never re-merged by coordinates.

Production bounds: node domain1048576, pairs2097152, distinct nets65536. Rows
contains4194304 uint64 words for both banks. Metadata[6] is magic, node domain,
pair count, active bank, nonempty net count, version. Config[8] is operation,
net, reset node domain, input count, four zeros. Reset=0, replace=1, get=2;
unrelated fields must be zero. Input/output node arrays each retain1048576
uint32 words. Result[5] is status, total pairs, total nets, version, returned
node count. Status0 success/1 invalid/2 capacity/3 version overflow; errors
clear the other result fields and preserve all persistent buffers and output.

Replace validates the complete sorted unique input, final pair/net capacities
and version before writing either bank. It copies unaffected prefix/suffix and
replaces the selected net in the inactive bank, then flips metadata. Empty
replacement removes the net; absent get returns count0 and keeps output words.
Get uses bounded binary searches and exports ascending canonical IDs, writing
only the logical output prefix. Reset changes metadata only. Internal state is
trusted to originate from valid operations; arbitrary corrupted row buffers are
outside the contract. Buffers must be disjoint and exclusively owned.

Copying the retained population on every successful replacement is a bounded
reference strategy, not a throughput optimization. Its memory traffic must be
measured. Version counts successful retention operations, including empty
replacements. The CPU bridge's unused argument buffers are CPU-only; RTL TBs
must always allocate all full declared port depths.

The isolated router uses this get result for bulk node occupancy release and
tree roots for bulk acquire/retention. Occupancy version therefore counts bulk
transactions instead of individual nodes. It does not affect search packet
cost/history contents. Final route nodes and edge traces remain host-visible
results. The outer scheduler and multi-component failure rollback remain host
work; no atomic multi-component commit is claimed.

CPU tests use an independent map/set oracle for6000 operations, including
3106 accepted and2894 rejected updates. Actual production calls fill2097152
pairs using two full-domain routes. The65536-net boundary is explicitly seeded
as valid state, not naturally generated by65536 operations. Tests cover both
banks' atomic rejection, absent/max-ID lookups, capacity, sorted uniqueness,
version saturation, full buffers, stale tails and guards under ASAN/UBSAN.

The frozen six-component memory plan excludes this seventh component. Device
integration needs new rows/meta BOs and sharing of tree roots with retention
input and retention output with old-node occupancy input. Native integration
and HLS results do not prove platform link, whole-router RTL or board execution.
