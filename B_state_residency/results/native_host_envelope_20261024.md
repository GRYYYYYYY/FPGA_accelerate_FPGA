# 原生主机边界的条件工作量（2026-10-24）

`analyze_native_host_envelope.py` 绑定已完成的原生16位全38回放、源码和向量审计，统计控制边界需求。结果为条件模型，不是新主机ABI、传输实现或硬件实测。

该轨迹21466914条公开命令、14047736次字段访问。TX/GEN16下，当前原生公开命令字段合计90bit，完整响应182bit，合计272bit。若所有命令/回复均固定宽度、不压缩地跨越外部主机边界，总逻辑字段位数折合729875076字节（272bit×命令数÷8，不含两方向各自逐消息字节对齐）；若**假设**命令对齐16B、回复32B，则1030411872字节。该对齐尚未实现，操作特定编码或压缩可改变数字，因此不是信息论下界。

EXPORT、BEAT和内部RF_MASK没有计入公开命令。页后备AXI负载474636672字节与主机控制可能位于不同物理链路，不能相加后称为PCIe流量。
