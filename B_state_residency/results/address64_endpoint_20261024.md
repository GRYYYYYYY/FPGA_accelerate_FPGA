# 64位后备基址接入结果

独立包装层提供一次性配置并锁定的64位基址，保持原32位相对地址引擎、192字节页和命令/数据协议。它不负责缓冲区分配、XRT/DMA控制或图搜索；默认源码与运行中的未包装组合全量保持冻结。接口见hardware/ADDRESS64_CONTRACT.md。

配置单元与两组32槽集成通过XSim2022.2及源码绑定审计：每组1778检查、288传输、8checkpoint、800阻塞周期。错误对齐、数值溢出、响应保持、配置锁定、冷复位均检查；进位基址用例覆盖AW11/AR88次跨低32位边界，独立核对完整高位与原页字节。v1/v2编译失败记录保留，未启动端点功能仿真。
