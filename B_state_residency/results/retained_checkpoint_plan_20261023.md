# 保留后备数据的标识回收：软件参考验证

全部38查询、14,047,736次真实字段访问通过，包括10,324,516读和3,723,220写。逐读比较捕获的原始位模式，每次访问另与逻辑字典比较，结束时核对全部已发布内容。输入沿用冻结的真实五字段捕获；没有截断大查询。

四个驻留页采用LRU，事务/槽代次均16位。接近有限ID边界时预留最多四个脏槽写回及一次缺页WB/RF预算，写回并释放全部驻留页，再重置ID；保持后备数据及frame分配。当前query/price由每个独立planner隐含固定。

这仅验证顺序软件参考的内容保持和有限ID预算。没有实现RTL checkpoint、排空/ACK顺序、旧响应隔离、host背压或多query拒绝；也未计入硬件checkpoint周期、真实DMA和平台开销。完整协议义务见 `hardware/CONNECTION_CHECKPOINT_DESIGN.md`，不能据此声称硬件加速。
