# 小页目录存储量核算

同为256个驻留节点，数据与有效位共35072bit。维持默认约30MiB后备数据池时，页数显著增加：

|配置|目录owner+published|索引|合计KiB|
|---|---:|---:|---:|
|64node_default|585125 bit|753664 bit|163.426|
|8node_default|4587520 bit|6815744 bit|1392.000|
|8node_trace_capacity_candidate|1835008 bit|3145728 bit|608.000|

按RTL数组声明核算，不含租约、控制、FIFO、codec、RAM端口/形状映射及复制，不等于综合资源。默认小页版1392KiB，原版163.426KiB，说明固定驻留节点数并不意味着固定总片上存储。

65536帧候选只覆盖当前轨迹峰值59843页，不等价于默认163840帧容量；仅列为未来可选容量实验，未替换正在综合/回放的默认配置，也未测试或综合该候选。需先取得默认资源结果，再决定是否研究可配置目录或其他元数据布局。
