# 真实标签访问的参数化页缓存分析

来源：`page_cache_20261022T194111Z/manifest.json`。仅首设计CPU TLD访问流：固定间隔1113查询、2399968次访问；独立尾部19查询、13751567次访问。两组分别统计，不合并为无偏总体。输入无截断并核验偏移及字节数，前后SHA一致。

模型：每查询冷启动、全相联LRU；每节点24B标签+4B epoch，每页另假设16B标签元数据。预算1/4/16MiB只是敏感性参数，不是U280可用容量声明。首次触页可本地初始化；本查询已触但被驱逐的页必须从后备存储读回。按整页读回计算字节；另提供每次触碰都脏的整页写回场景，查询结束直接丢弃仍驻留页。未计DDR突发、排队、并发bank、压缩、预取抑制、DMA协议、历史价格和全局占用。TLD引用不等于硬件内存事务，没有周期/带宽/加速比。

现有生命周期规格将整个查询访问的页持有租约，拒绝查询中回收；本LRU模型尚未实现此处所需的运行中写回/换入协议。必须在解除物理槽租约前完成脏数据保存，并在换入时验证design、context、query/price版本和页身份，不能把LRU驱逐等同于丢弃仍有效的距离标签。实际运行中换页仍待实现与验证。
