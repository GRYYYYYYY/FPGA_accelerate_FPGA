# 有限完成队列与页数据值组合验证

新增src/finite_page_values.py，组合有限wire ledger、有界传输队列和页值。它是独立CPU事件模型，不是原有page_residency.py的替换，也未进入真实C++路由。

dirty淘汰在提交请求时冻结数据快照，并保持原槽租约。peer publish阶段先在对应有限QueryKey的后备命名空间提交数据，再由后续host deliver确认回收槽；模拟器方法内部视为原子事件。取消query不让新query重用旧命名空间。迟到旧写回仍可产生旧空间副作用，旧完成返回stale并只释放自己的槽，新空间及新槽值不变。原槽在确认前不可读写、不可复用。

refill在peer publish时取得后备快照，直到host收到valid完成才向槽发布。取消后迟到refill丢弃暂存值，不向新query槽发布。重复请求在peer去重，不重复进入work或执行数据副作用；重复完成不重复发布值。读写均深拷贝，调用者修改返回对象不会改变槽数据。pin完成与IO互斥，全部确认前不能淘汰。

资源耗尽时阻塞。需要refill的request在绑定前检查队列与事务号容量，失败不消耗槽代次；本模型限单owner，因此检查至提交之间没有竞争。排空时停止发起，丢弃无租约的旧标签，等待pending、payload暂存及重复完成全部清空，peer seal与transport finish成功后才清理查询命名空间并重用有限编号。该fence取消当前查询，不保持旧距离标签有效；不包含全局占用和历史价格状态。

8项专项检查及全套64项Python检查通过。包括取消发生在peer写入之前/之后、迟到refill、确认前不可见、重复包副作用一次、pin阻塞、refill背压不消耗代次以及实际编号回绕后读默认值。2000步小位宽随机访问带查询排空恢复：超过1000步成功访问、超过50次排空、超过100次写回和10次换入，逐读以及每步完整resident+backing逻辑值映射均对照独立oracle，不仅检查运行结束状态。

本模型仍依赖封闭队列契约：所有迟到包都存在于已建模队列，无排空后从隐藏链路注入旧包，peer去重状态不丢失，单一host不重放旧query/binding。控制fence仍是模拟方法而非实际有限控制包。没有丢包/超时重试、设备重置恢复、真实物理DDR地址分配/回收、内存屏障或cache一致性验证。后备命名空间是逻辑字典，保存数据可为Python对象，未提供固定宽度payload、总字节上限或OOM行为；不能直接宣称可综合/有限硬件总容量。

性能为空，未宣称GPU/FPGA或端到端加速；现有真实CPU基线保持冻结。下一步补真实wire控制握手的有限fence标识和旧ACK隔离，或把闭合队列页值模型接入真实地址回放；两者都必须保留命名空间与payload租约，不能将host收到ACK等同所有DMA侧副作用已撤销。
