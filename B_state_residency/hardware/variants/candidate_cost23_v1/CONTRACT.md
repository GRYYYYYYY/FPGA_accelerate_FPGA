# Internal cost23 production and arithmetic

candidate_cost23_engine derives from the frozen params wrapper. It keeps per-expand immutable State reads and actual owner/history/price/net prefetch, CLEAR, native prev write ACK, parent upstream read, fresh effectiveY and actual center distance. Allowed candidates then enter cost23_inputs, which snapshots all inputs, invokes actual geometry_step and exact cost_step, and holds the23-word packet and5-word result until candidate retirement. SKIP has no cost call. k_busy joins the mutation/configuration fence. Full query2/price4/version32/design64 identity is retained beyond the narrower arithmetic ABI.

Config14 sink begin coordinates come from the existing actual metadata service. CrossSLR profiles additionally request sink SLR, child post-prev SLR and, only if different, child Laguna columns through a third coordinate client. Geometry inputs use child effectiveY after prev; connection flags, SLL length and immutable State weights come from the real connection record. The13-word geometry ABI supplies deltaX/deltaY/distance with explicit status. Its last detour word is unused by the frozen checked geometry implementation; the prior original-geometry equivalence gate covers the simplification.

Inputs follow hardware/hls/search_cost/ARCHITECTURE.md, word0 low. Graph length is signed16 extended to32. Net fanout/doubleHPWL are the imported signed integers. Actual refs select sharing; occupancy-minus-same-net selects the price before entry. Design history stays independent of native labels. This stage never modifies lb/upstream/visited or offers a cost into Frontier.

The current real initial serial non-timing profile is landmark-inactive and crossSLR0. Its unused landmark pair words are0. Landmark-active requests explicitly stop with status6 before any arithmetic; actual landmark storage/target words are still required before that profile can be supported. Do not silently replace that missing data by zeros. CrossSLR branch tests using mock coordinate replies are separate from the real-graph gate.

CPU golden uses the original evaluateCostAndPush arithmetic body verbatim and the real non-timing State initializer; only final push is replaced by logging. The parent/child labels and original candidate/prefix replay are otherwise unchanged. Thus these are real-graph, scripted query/prefix cost comparisons, not a live full-route cost trace. Four SLL beginY patches and hasLaguna override remain explicit stress inputs; current allowed occupancy/refs/index are0, not combined with the prior nonzero-owner gate.

No cost label commit, OFFER/recursive lookahead, complete search/traceback/owner-reference commit, joined fault/drain/reset/reload, default-directory new composition, joint synthesis, platform timing or board acceleration is established here. New geometry collector normal calls are verified by actual kernel integration; this is not exhaustive collector fault/reset coverage.
