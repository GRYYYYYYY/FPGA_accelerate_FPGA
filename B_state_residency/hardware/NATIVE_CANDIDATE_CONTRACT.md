# 原生组合候选边界

候选源包位于`hardware/candidates/native_epoch6_record/`，顶层`memory_scratch_endpoint_small_staticcodec`。它是标签页状态/后备存储组件，不执行完整图搜索、拥塞更新或同网路由树算法。源包与默认RTL、既有基线分开；默认实验配置未自动切换。

固定验证配置为32槽、每页8节点/192字节，默认163840后备帧（30MiB页载荷），INDEX/HASH18、EPOCH6、TX/GEN16、TAG2。端口slot5/page21/query2/price4/offset3位，完整记录160位，其中有效字段136位。原生AXI地址是32位相对偏移；高地址配置由另一个独立包装层提供，不在此源包中。

| 公开op | 含义 |
|---|---|
| 0 | QUERY |
| 1 | BIND |
| 2 / 3 | READ / WRITE |
| 4 | RELEASE |
| 5 / 6 | 完整页写回 / 回填 |
| 10 / 11 | BEGIN_FENCE / FINISH_FENCE |
| 12 | CHECKPOINT，复用有限页槽标识并保留当前查询已提交的后备页 |

7..9和13..15为BAD，不允许外部注入BEAT/EXPORT/COMPLETE。单命令在途，valid/ready握手；响应背压时稳定。FINISH在排空条件未满足时可能返回FENCE_WAIT，调用方不得将其当作回收完成。CHECKPOINT要求合法查询生命周期、已释放全部绑定且无租约；它不是设计级状态清零。

4位响应status为0..7页槽状态，8后备未就绪，9后备满，10存储/内部协议错误。WB/RF成功必须晚于整页校验、实际内存成功、页COMPLETE与地址RETIRE。故障封锁及租约隔离保持；冷复位是破坏性复位，不是热迁移或在途恢复。

EPOCH6的目录63次回收后需要全表清理；EPOCH8对应255次。当前38查询没有发生目录epoch回绕，不能由其相同周期推出长生命周期吞吐相同。默认hash18每次清表262144周期，在10ns计数模型中为2.62144ms清表工作量，完整阻塞还包含fence/协议；应结合真实回收频率评估。32帧组合70回收用例和独立默认容量目录回绕验证覆盖正确性，不能替代全设计长期性能测量。

源包提供哈希验证、checkpoint/回绕仿真和相对路径OOC综合。重建已运行，资源及Vivado综合校验和与冻结输入一致。当前内部10ns约束通过但缺外部IO延迟和上游物理时钟上下文；没有平台/XRT/板上或完整路由加速结论。
