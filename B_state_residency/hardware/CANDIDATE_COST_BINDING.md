# Candidate to cost integration boundary

Source evidence is `results/candidate_cost_binding_20261025.json`, generated by `scripts/analyze_cost_binding.py` from the frozen original CPU router. It records exact source hashes/locations and ordering, not a joined cost implementation.

The existing candidate engine completes device-side accessibility decisions and holds an operation lock. The existing cost service performs exact 23-word arithmetic, but its inputs currently come from an independent fixture. Joining them requires actual state producers; passing another host-computed cost packet would not complete the intended device data path.

The required child sequence is:

1. Retain access result and child/parent/sink/net/query/price identity. SKIP has no label or frontier mutation.
2. For EARLY, complete query-local Frontier CLEAR5 before changing the target child's labels.
3. Obtain same-net reference count and occupancy under the continuous operation lock. An earlier owner response is reusable only with matching identity and no intervening design mutation; the current access result does not itself export a reusable owner snapshot.
4. Write child.prev=parent and wait for a successful acknowledgement.
5. Read parent upstream and the child's post-prev coordinates. For an SLL, prev changes effective endY and therefore bounding/SLR/cost geometry. An access-stage coordinate snapshot may be stale. The original cost helper also uses effective endY for distance to the net center.
6. Read actual design history, selected present-congestion price, net center/fanout/HPWL, node base cost/length and connection weights; construct integer geometry and the 23-word arithmetic input. Maintain the original binary32 rounding and association rules.
7. Complete exact arithmetic, then write child.lb, child.upstream and child.visited=sequence successfully, in original order. visited is set on first push, after cost computation; it must not be moved before post-prev geometry.
8. For lookahead, immediately expand recursively without OFFER. Otherwise complete Frontier OFFER. FULL/fault after label writes fails the query; it is not permission to skip the node and continue. Nested EARLY propagates through saved parent contexts.

Source ownership is explicit:

| Data | Existing authority | Missing integration |
|---|---|---|
| Type/coordinates/baseCost/length | Actual graph AXI attributes | Post-prev geometry/cost packet producer |
| prev/upstream/lb/visited/target | Actual paged query labels | Internal acknowledged cost/commit writer and arbitration |
| Same-net refs and distinct-net occupancy | Actual owner AXI store | Identity-bound cost snapshot and future route commit |
| Historical congestion | Original CPU global dyn[id].hist | Independent design-level storage/update; never query-epoch-cleared |
| Present congestion | CPU presentCongestionCosts and factor/version | Device table, bounds and update fence; 4-bit price identity alone is not table contents |
| Net center/fanout/doubleHPWL and weights | CPU nets/connection/State | Imported validated parameters and request lifetime snapshot |
| Heuristic integer geometry/landmarks | Standalone helpers and CPU data | Actual table/input binding and supported sentinel/overflow contract |
| Frontier and recursive parent contexts | Standalone Frontier service | Single search controller, saved ordered children, stack limits and coherent checkpoints |

A query keeps price fixed but design history/occupancy persist beyond it. Resetting controls does not roll back failed writes. Recovery must drain accepted traffic and explicitly reload affected design state. Completing this boundary still leaves query initialization, POLL/target handling, traceback, route reference commit, full CPU comparison and platform/board validation.
